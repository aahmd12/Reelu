# 📱 Reelu Application

## 📌 Tentang Aplikasi Reelu

**Reelu** adalah aplikasi modern berbasis **Flutter** yang dirancang untuk memberikan pengalaman pengguna yang intuitif, cepat, dan responsive lintas platform (*Cross-Platform*).

## 🛠️ Persyaratan & Ekstensi VS Code

Sebelum menjalankan proyek, pastikan Anda telah memasang **Android Studio** dan ekstensi pendukung di **Visual Studio Code**.

### 1. IDE & Tools

* **Android Studio:** [Android Studio Ladybug / Koala / Quail](https://developer.android.com/studio?hl=id)

* **Visual Studio Code** (atau IDE pilihan Anda)

### 2. Ekstensi VS Code yang Direkomendasikan

Buka menu extensions di VS Code (`Ctrl+Shift+X` / `Cmd+Shift+X`) dan install ekstensi berikut:

* **Flutter** (`Dart-Code.flutter`)

* **Dart** (`Dart-Code.dart-code`)

* **Kotlin Language Support** (`fwcd.kotlin`)

* **Extension Pack for Java** (`vscjava.vscode-java-pack`)

## 🚀 Cara Menjalankan Proyek (How to Run)

Ikuti langkah-langkah di bawah ini untuk menjalankan aplikasi pada lingkungan lokal Anda:

### 1. Bersihkan Build Cache & Dapatkan Dependensi

Buka terminal pada direktori proyek Anda dan jalankan perintah berikut:

```
# Membersihkan cache build lama
flutter clean

# Mengunduh seluruh paket/dependensi proyek
flutter pub get

```

### 2. Jalankan Aplikasi

#### **Cara 1: Menggunakan Menu Interaktif**

Jalankan perintah berikut pada terminal:

```
flutter run

```

Setelah itu, pilih perangkat target yang tersedia dengan menekan nomor opsi:

* `[1]` **Windows** (`windows`)

* `[2]` **Chrome** (`chrome`)

* `[3]` **Edge** (`edge`)

#### **Cara 2: Menjalankan Langsung ke Target Tertentu**

Anda juga dapat menentukan platform target secara langsung lewat flag `-d`:

```
# Menjalankan di Google Chrome
flutter run -d chrome

# Menjalankan di Microsoft Edge
flutter run -d edge

# Menjalankan di Windows Desktop
flutter run -d windows

```
